SpineMotion

Your Moves. Your Challenge.

在浏览器里记录你的动作，邀请朋友复刻，让本地 AI 解释你们有多默契——全程不上传视频。

Scenario

为什么做这个？

运动对比通常依赖教练的人眼和经验，视频对比工具又往往只做"并排播放"，无法回答 "哪里不像、差多少、在哪个瞬间"。 SpineMotion 把姿态捕捉、时序对齐与可解释评分放进一个本地网页， 让"学动作、比动作、复盘动作"变成一场即时、公平、有趣的对战。

Experience

三个核心体验

01

Capture · 记录

MediaPipe 33 点骨架实时捕捉，头肩髋膝踝完整入镜检测，5–15 秒一次干净录制，自动质量把关。

02

Challenge · 复刻

玩家 A 记录参考动作，玩家 B 观看回放后复刻。DTW 自动对齐两段时间轴，消除速度快慢带来的误判。

03

Explain · 解释

双骨架并排 / 重叠回放、关节差异中文排名、差异时段时间轴跳转，以及自然语言评分总结与 JSON / CSV 导出。

Innovation

产品创新点

  • 尺度无关的公平比对：髋部锚点 + 肩宽归一化，站位远近不影响分数
  • 时序动态对齐：DTW 而非逐帧硬对齐，允许合理速度差异
  • 可解释评分：娱乐 / 研究双模式，给出"哪里不像"而非一个神秘数字
  • 纯本地隐私：不上传视频，断网可运行，无云端依赖
  • 双人竞技化：用挑战与默契把枯燥的形态对比变成游戏
  • 零成本演示：一台 Mac + Chrome 即完整演示环境
Architecture

技术架构

纯前端本地架构：浏览器摄像头帧 → MediaPipe Pose Landmarker（WASM / GPU）→ 关键点轨迹录制 → DTW 对齐与尺度归一化 → 可解释评分引擎 → Canvas 双骨架回放。 无后端服务，无数据库，无用户账户。
