## 紧急恢复步骤

- 页面异常 → 刷新页面（Cmd+R）。
- 摄像头无画面 → 检查 Chrome 与 macOS 摄像头权限；点"刷新设备"。
- 端口占用 → 停止占用进程后重新 `npm run dev`。
- 模型缺失 → `npm run sync:assets` 后重启。
