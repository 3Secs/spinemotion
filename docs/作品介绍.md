# 作品介绍

## SpineMotion — Your Moves. Your Challenge.

**一句话介绍**：SpineMotion 是一个完全在浏览器本地运行的人体运动应用——记录你的动作、邀请朋友复刻，让本地 AI 解释你们有多默契，全程不上传任何视频。

---

## 问题与场景

学动作、比动作、复盘动作，通常依赖教练的人眼和经验；视频对比工具往往只做"并排播放"，无法回答三个问题：

- **哪里不像** —— 哪个部位偏差最大？
- **差多少** —— 偏差是否可量化？
- **在哪个瞬间** —— 差异发生在动作的哪一时段？

SpineMotion 把姿态捕捉、时序对齐与可解释评分放进一个本地网页，让双人运动对比变成一场即时、公平、有趣的挑战：适合运动教学、舞蹈/健身动作比对、双人默契游戏，以及任何"两人做同一动作看谁更接近"的现场场景。

---

## 三个核心体验

### 01 · Capture 记录
MediaPipe 33 点人体骨架实时捕捉，头肩髋膝踝完整入镜实时检测；5–15 秒一次干净录制，附 3 秒倒计时与自动/手动两种结束方式，质量不合格自动把关。

### 02 · Challenge 复刻
玩家 A 记录参考动作，玩家 B 观看回放后复刻。DTW 动态时间对齐自动消除两人速度快慢造成的误判，尺度归一化消除站位远近的影响——比的是动作本身，而不是位置和速度。

### 03 · Explain 解释
结果页给出综合分 + 姿态分 + 时间分，附自然语言总结；双骨架并排 / 重叠回放、关节差异中文排名（肩/肘/腕/髋/膝/踝）、差异时段时间轴跳转，以及 JSON / CSV 数据导出。不说"你们像不像"，而是说清"哪里不像、差多少、在哪一秒"。

---

## 产品创新点

1. **尺度无关的公平比对**：髋部锚点 + 肩宽归一化，站位与镜头远近不影响分数；
2. **时序动态对齐**：DTW 而非逐帧硬对齐，允许合理的速度差异；
3. **可解释评分**：娱乐 / 研究双模式（娱乐默认、末端关节降权更友好），给出"哪里不像"而非一个神秘数字；
4. **纯本地隐私**：不上传视频，不依赖云端，断网可运行；
5. **双人竞技化**：用挑战与默契把枯燥的形态对比变成游戏；
6. **零门槛演示**：一台 Mac + Chrome 即可完整演示，另提供免安装便携包。

## 技术架构

纯前端本地架构，无后端、无数据库、无用户账户：

```
浏览器摄像头帧
  → MediaPipe Pose Landmarker（本地 WASM / GPU 推理）
  → 关键点轨迹录制（Ghost 动作）
  → DTW 时间对齐 + 髋部锚点/肩宽尺度归一化
  → 可解释评分引擎（娱乐 / 研究双模式）
  → Canvas 双骨架同步回放 + 差异可视化 + 导出
```

| 组成 | 技术 |
| --- | --- |
| 前端 | React 19 + TypeScript + Vite |
| 姿态推理 | MediaPipe Tasks Vision（Pose Landmarker Lite），GPU / CPU 自动回退 |
| 对齐算法 | DTW 时间对齐 + 尺度归一化 |
| 测试 | Vitest（157 项单元/算法测试） |
| 运行时 | 浏览器本地 WASM，模型与推理文件随包内置，断网可用 |

## 真实已实现功能

- **实时捕捉**：摄像头设备选择（含 iPhone 连续互通相机）、Upper / Full Body 两种采集模式、骨架/网格/解剖标注开关、真实 FPS 与推理耗时显示；
- **Motion Ghost（动作数字分身）**：关键点录制、真实时间戳回放、0.5×/1×/1.5× 倍速、半透明参考骨架叠加、本地 JSON 动作库；
- **Motion Arena（动作竞技场）**：双人完整流程（准备 → 玩家A → 玩家B → 分析 → 结果 → 再来一局）、质量门控（不合格拒绝评分并给中文原因）、双模式评分、双骨架并排/重叠回放、关节差异排名、差异时段跳转、JSON/CSV 导出。

---

## 隐私保护声明

- 不保存原始视频，不上传视频；摄像头帧只进入本地 `<video>` 与本地 WASM 推理；
- 模型与推理 WASM 全部随应用内置，断网可用；
- 页面 CSP 阻断第三方网络连接。

## 非医学诊断声明

**本作品不是医疗器械，不提供临床诊断**。运动分析结果仅作运动展示与娱乐参考，不替代任何专业医学评估。
